# Solución de Business Intelligence - NANOPARURO

## Descripción

Implementación de una solución de inteligencia de negocios orientada al análisis comercial de NANOPARURO.

## Componentes

- Diseño del modelo dimensional estrella.
- Implementación del Data Mart en SQL Server.
- Proceso ETL mediante SQL Server Integration Services (SSIS).
- Dashboard interactivo en Power BI.
- Indicadores clave de rendimiento (KPI).
- Análisis de ventas, clientes, productos y vendedores.

## Tecnologías utilizadas

- SQL Server.
- SQL Server Management Studio.
- Visual Studio.
- SQL Server Integration Services.
- Power BI Desktop.
