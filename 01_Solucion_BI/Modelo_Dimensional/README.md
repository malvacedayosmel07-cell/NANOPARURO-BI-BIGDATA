# Modelo dimensional - NANOPARURO

## Descripción

El modelo dimensional utiliza un esquema estrella orientado al análisis de las ventas comerciales de NANOPARURO.

## Tabla de hechos

- FACT_VENTAS: almacena las transacciones comerciales, cantidades, precios, costos de flete e importes.

## Tablas de dimensiones

- DIM_CLIENTE: información de los clientes.
- DIM_PRODUCTO: información de los productos y categorías.
- DIM_FECHA: información temporal de las ventas.
- DIM_GEOGRAFIA: información de ciudades, estados y regiones.
- DIM_VENDEDOR: información de los vendedores.

## Objetivo

Facilitar el análisis multidimensional de las ventas y generar información para la toma de decisiones comerciales.
