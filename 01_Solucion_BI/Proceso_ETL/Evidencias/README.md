# Evidencias del proceso ETL - NANOPARURO

## Descripción

Esta carpeta contiene las evidencias de la implementación y ejecución del proceso ETL desarrollado mediante SQL Server Integration Services (SSIS).

## Evidencias

- Flujo de control del proceso ETL.
- Flujo de datos para la extracción y carga.
- Ejecución exitosa del paquete SSIS.
- Validación de los registros en SQL Server.

## Resultados

El proceso ETL permitió cargar los 74 registros originales en el Data Mart, obteniendo 74 pedidos únicos y 0 registros duplicados.

## Objetivo

Demostrar el correcto funcionamiento del proceso de extracción, transformación y carga de los datos comerciales de NANOPARURO.
