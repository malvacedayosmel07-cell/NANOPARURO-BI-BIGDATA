# Proyecto SSIS - NANOPARURO

Proyecto de integración de datos desarrollado en Visual Studio mediante SQL Server Integration Services (SSIS).

## Archivos del proyecto

- ETL_Nanoparuro_V2.database
- ETL_Nanoparuro_V2.dtproj
- Package.dtsx
- Project.params

## Ejecución

1. Abrir el proyecto en Visual Studio.
2. Configurar las conexiones CN_Origen y CN_Destino.
3. Verificar las bases de datos de SQL Server.
4. Ejecutar el paquete Package.dtsx.
5. Validar los resultados de la carga de datos.
