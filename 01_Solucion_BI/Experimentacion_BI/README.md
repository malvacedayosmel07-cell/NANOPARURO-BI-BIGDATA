# Experimentación de la Solución BI - NANOPARURO

## Descripción

Esta carpeta contiene la documentación de las pruebas experimentales realizadas para evaluar el comportamiento del proceso ETL de la solución Business Intelligence del proyecto NANOPARURO.

## Objetivo

Evaluar el rendimiento del proceso de extracción, transformación y carga de datos utilizando diferentes volúmenes de registros.
