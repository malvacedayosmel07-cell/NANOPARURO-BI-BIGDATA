# Dashboard Power BI - NANOPARURO

## Descripción

Implementación de un dashboard interactivo de inteligencia de negocios para el análisis comercial de NANOPARURO, utilizando los datos almacenados en el Data Mart BI_Nanoparuro_V2.

## Objetivo

Facilitar el análisis del comportamiento de las ventas, clientes, productos y vendedores mediante indicadores clave de rendimiento y visualizaciones interactivas que apoyen la toma de decisiones comerciales.

## Indicadores clave de rendimiento (KPI)

- Ventas totales.
- Total de pedidos.
- Unidades vendidas.
- Total de clientes.
- Total de productos.
- Ticket promedio.
- Costo total de flete.
- Importe con flete.
- Total de vendedores.

## Filtros interactivos

- Fecha de venta.
- Categoría de producto.
- Ciudad.
- Tipo de cliente.

## Tecnologías utilizadas

- Microsoft Power BI Desktop.
- Power Query.
- Lenguaje DAX.
- Microsoft SQL Server.

## Fuente de datos

Base de datos BI_Nanoparuro_V2, alimentada mediante el proceso ETL desarrollado en SQL Server Integration Services (SSIS).
