# Dashboard Big Data - NANOPARURO

## Descripción

Dashboard interactivo desarrollado en Databricks para
el análisis comercial de NANOPARURO.

## Características

- Indicadores clave de rendimiento (KPI).
- Análisis de ventas, clientes y productos.
- Análisis de distribución geográfica.
- Evaluación de tiempos de entrega.
- Filtros interactivos.
- Visualización de información comercial.

## Tecnologías utilizadas

- Databricks.
- Apache Spark.
- Spark SQL.
- Delta Lake.
- Databricks AI/BI Dashboards.
