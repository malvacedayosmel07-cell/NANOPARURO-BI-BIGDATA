# Experimentación Big Data - NANOPARURO

## Descripción

Experimentación orientada a evaluar el procesamiento de
datos comerciales mediante tecnologías Big Data.

## Aspectos evaluados

- Procesamiento de grandes volúmenes de datos.
- Rendimiento de consultas.
- Generación de datos sintéticos.
- Validación de registros.
- Escalabilidad del procesamiento.
- Uso de Apache Spark y Delta Lake.

## Herramientas utilizadas

- Databricks.
- PySpark.
- Spark SQL.
- Delta Lake.
