# Solución Big Data - NANOPARURO

## Descripción

La solución Big Data está orientada al procesamiento,
transformación y análisis de datos comerciales de
NANOPARURO mediante Databricks y Apache Spark.

## Objetivo

Implementar una solución tecnológica escalable que
permita procesar volúmenes crecientes de datos y generar
indicadores para la toma de decisiones comerciales.

## Componentes de la solución

- Identificación y consolidación de datos.
- Arquitectura tecnológica Big Data.
- Procesamiento mediante DataFrames de Apache Spark.
- Análisis exploratorio de datos (EDA).
- Limpieza y transformación de datos.
- Persistencia mediante tablas Delta en Databricks.
- Indicadores clave de rendimiento (KPI).
- Dashboard interactivo.
- Validación de la calidad de los datos.

## Volumen de datos

La solución parte de 74 pedidos originales y se amplía
mediante la generación de datos sintéticos para evaluar
el procesamiento de mayores volúmenes de información.

## Tecnologías utilizadas

- Databricks.
- Apache Spark.
- PySpark.
- Spark SQL.
- Delta Lake.
- Databricks AI/BI Dashboards.

## Resultados

La solución permite analizar las ventas, clientes,
productos, regiones, costos de transporte, calificaciones
y cumplimiento de entregas.

## Evidencias y replicación

Se incorporarán los notebooks, datasets, diagramas,
scripts, evidencias y procedimientos necesarios para
reproducir la solución implementada.
